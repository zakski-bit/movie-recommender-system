Arsitektur RecommenderNet

  • User Latent Embeddings: 610 pengguna dipetakan ke vektor 50 dimensi (bobot he_normal).
  • Movie Latent Embeddings: 9.719 film dipetakan ke vektor 50 dimensi (bobot he_normal).
  • User & Item Bias: Skalar bias independen untuk menangkap kebiasaan rating personal dan popularitas film.
  • Interaction: Vektor dot-product + bias diaktivasi dengan Sigmoid untuk rentang normalisasi $[0, 1]$.
  • Total Bobot Terlatih: 526.789 parameter.

Diagnosis Overfitting & Rencana Optimasi

Kurva pelatihan menunjukkan dinamika nyata:

  • Epoch Optimum: Validasi terendah tercapai di Epoch 3 (Loss: 0.6002, RMSE: 0.1903).
  • Gejala Overfitting: Pada Epoch 20, loss latih turun ke 0.5163 (RMSE 0.0458), namun loss validasi naik ke 0.6423 (RMSE 0.2177) — kesenjangan 5x lipat.
  • Akar Masalah: Regularisasi L2 (1e-6) terlalu lemah untuk menahan 526k parameter pada 80k sampel latih.
  • Solusi Teruji: Penambahan EarlyStopping(patience=3), peningkatan L2 ke 1e-4, dan reduksi embedding ke 16–32.
